# Ukentlig ritual

## Søndag (15–20 min)

1. Start coach-bot hvis den ikke kjører: `./coach-bot/scripts/start.sh`
2. Slack DM til Lofoten Coach: **«ukestatus»** (eller fri formulering)
3. Les anbefalingen – noter risiko og «neste uke»
4. Oppdater [CURRENT_STATUS.md](../LOFOTEN-2027/CURRENT_STATUS.md)
5. Legg **gro plan** for kommende uke som events i **intervals.icu**

## Valgfritt i uken

| Når | Handling |
|-----|----------|
| Kveld før treningsdag | DM: «hva i morgen?» |
| Ved tvil om form | DM: «hvordan ligger jeg an?» |
| Subjektivt (smerte, RPE) | Cursor-chat eller senere `/logg` til repo |

## Etter økt

- Intervals er sannhet – ikke dupliser full økt i `05_TRENINGSDATA.md`
- Bruk `05_` kun for notater Intervals ikke fanger
